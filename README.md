# מלך החשבון 🦉

משחק חשבון קליל לילדים בני 8-12 — תרגול לוח הכפל, חיבור וחיסור.

**[▶️ שחקו כאן](#)**

## מה יש במשחק

- **4 מצבים:** כפל (2-10), חיבור (עד 100), חיסור (תמיד תוצאה חיובית), מעורב
- סבב של 10 שאלות, 4 תשובות לבחירה
- ניקוד עם בונוס רצף — 10 נקודות לתשובה נכונה, עד 40 ברצף
- משוב מיידי, אנימציות וקונפטי בסיום מוצלח

## טכני

קובץ HTML יחיד, בלי תלויות ובלי build. פשוט לפתוח את `index.html` בדפדפן.

- עברית RTL
- אפשר לענות גם עם המקשים 1-4
- נגיש: כפתורים סמנטיים, `aria-live`, ניווט מקלדת, כיבוד `prefers-reduced-motion`
- רספונסיבי לנייד

## הרצה מקומית

```bash
npx serve .
```
